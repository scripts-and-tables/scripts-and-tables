Executive summary

Excel basics (UA) is a free Excel course for absolute beginners, taught in Ukrainian — removing the language barrier that keeps many newcomers from getting comfortable with spreadsheets.

Across sixteen short, sequential lessons it takes a complete beginner from opening Excel for the first time to writing useful formulas and looking up data.

What you'll learn

Sixteen lessons build up in order, from the interface to real formulas.

  • Getting started (lessons 1–10)What Excel is, core terminology and components, creating and saving files, navigation, and the quick-access tools.
  • Data & formulas (lessons 11–16)Entering data, the formula bar and context menus, core functions (SUM, MIN, MAX, AVERAGE), conditional formulas (SUMIF, COUNTIF), and VLOOKUP.

How it's delivered

Each lesson is a short YouTube video paired with practice, free and publicly available.

  • Bite-size videosSixteen focused lessons hosted on YouTube.
  • Practical exercisesHands-on practice alongside each lesson.
  • Free & openFree on YouTube, with the course material on GitHub.

By the end, a complete beginner can confidently navigate Excel, enter and manage data, and use everyday functions — including conditional logic and lookups — in their own spreadsheets.
